# @keel/api-client

Generated. Never hand-edited.

This package is produced by `orval` from the backend's OpenAPI spec
(`/api/v1/schema/`) and the allauth headless spec (`/_allauth/openapi.json`).
Phase 1 adds the spec and the orval config that generates into `src/`; until
then this package is an empty placeholder so the workspace graph resolves.

Regenerate with the workspace's `generate` script once it exists — do not
edit files under `src/` by hand, they are overwritten on every run.
