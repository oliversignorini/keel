# @keel/api-client

Generated. Never hand-edited.

This package is produced by `orval` from the backend's OpenAPI spec
(`/api/v1/schema/`) and the allauth headless spec (`/_allauth/openapi.json`).
The two specs are merged by `scripts/merge_openapi.py` into
`openapi.merged.json`, which orval reads to generate into `src/generated/`.

Regenerate with `pnpm --filter @keel/api-client generate` — do not edit files
under `src/generated/` by hand, they are overwritten on every run.
